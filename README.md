# 🎯 Hangman Game

## 📌 Description

Hangman is a simple text-based word guessing game developed using Python.

The player has to guess a randomly selected word one letter at a time.

The player can make a maximum of 6 incorrect guesses before the game ends.

## 🎮 Features

- Randomly selects a word
- Uses 5 predefined words
- Allows one-letter guesses
- Maximum 6 incorrect guesses
- Displays the current progress of the word
- Displays previously guessed letters
- Prevents repeated guesses
- Provides win and lose messages
- Allows the player to play again
- Console-based application

## 🛠️ Technologies Used

- Python
- Random module
- While loops
- If-else statements
- Strings
- Lists
